# Machine Learning Lab 2

## Practical 2 – Linear Regression

This repository contains the implementation of Machine Learning Lab 2, focusing on data analysis and the application of a Linear Regression model using Python.

## Contents

- **ML_Practical_2.ipynb** – Jupyter Notebook containing the complete code, preprocessing steps, model implementation, and analysis.
- **processes2.csv** – Dataset used to perform the practical.

## Tools & Libraries

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Aim

To develop and evaluate a Linear Regression model for predicting vehicle prices using the given dataset.

## Dataset

The practical uses `processes2.csv`, which contains information about vehicles and their corresponding selling prices.

## Work Performed

- Loaded and examined the dataset.
- Performed basic data analysis and preprocessing.
- Explored relationships between selected features.
- Trained a Linear Regression model.
- Generated price predictions.
- Evaluated the model using regression performance metrics.

## Conclusion

The practical demonstrates the use of Linear Regression for continuous-value prediction. It also provides experience in preparing data, training a machine learning model, generating predictions, and evaluating the obtained results.
