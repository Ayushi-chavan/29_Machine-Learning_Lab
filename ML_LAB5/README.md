# Machine Learning Lab 5

## Practical 5 – K-Nearest Neighbors (KNN) for Classification and Regression

### Aim
To implement the K-Nearest Neighbors (KNN) algorithm for classification and regression.

### Objective
To understand the working of the KNN algorithm and evaluate its performance using suitable metrics.

### Dataset
The practical uses the Diabetes dataset (`diabetes.csv`) to analyze patient data and predict diabetes outcomes.

### Files Included
- `ML_Lab5.ipynb` – Jupyter Notebook containing the implementation and analysis.
- `diabetes.csv` – Dataset used for KNN classification.
- `README.md` – Description of the practical.

### Tools and Libraries
- Python
- Jupyter Notebook / Google Colab
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

### Practical Work
- Loaded and explored the Diabetes dataset.
- Visualized the distribution of diabetes outcomes and dataset features.
- Checked missing values in the cleaned dataset.
- Used pair plots to examine relationships between selected features.
- Implemented the K-Nearest Neighbors (KNN) classification algorithm.
- Compared training and testing accuracy for different values of K.
- Evaluated model performance using classification metrics.

### Conclusion
The practical demonstrates the implementation of the KNN classification algorithm using the Diabetes dataset. Data visualization and preprocessing were performed, and different values of K were compared to understand their effect on model accuracy.
