# Machine Learning Lab 4

## Practical 4 – Decision Tree Classification

This repository contains the implementation of a Decision Tree Classification model using the WineQT dataset. The practical focuses on data exploration, preprocessing, visualization, and classification using Python.

## Files Included

- **ml4.ipynb** – Jupyter Notebook containing the complete implementation and analysis.
- **WineQT.csv** – Dataset used for training and testing the classification model.

## Objective

To implement the Decision Tree Classification algorithm on a suitable dataset and evaluate its classification performance.

## Tools and Libraries

- Python
- Jupyter Notebook / Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

The practical uses the **WineQT dataset**, which contains different chemical properties of wine along with its quality value. The dataset is explored and prepared before applying the classification algorithm.

## Practical Work

- Loaded and inspected the dataset.
- Checked the structure and data quality.
- Visualized feature distributions using boxplots.
- Examined relationships between variables using a correlation heatmap.
- Detected and removed outliers using the IQR method.
- Prepared the data for classification.
- Implemented a Decision Tree Classifier.
- Evaluated the model using classification metrics.

## Conclusion

The practical demonstrates the application of Decision Tree Classification to the WineQT dataset. Data exploration and preprocessing were performed before training the model, followed by evaluation of its classification performance.
