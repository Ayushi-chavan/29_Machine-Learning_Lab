# Machine Learning Lab 3

## Practical 3 – Find-S and Candidate Elimination

This repository contains the implementation of Find-S and Candidate Elimination algorithms using the Enjoy Sports dataset. The practical demonstrates how hypotheses are generated and updated from labelled training examples.

## Files Included

- **ML_Lab3.ipynb** – Jupyter Notebook containing the implementation of both algorithms.
- **EnjoySports.csv** – Dataset used for training and concept learning.

## Objective

To implement Find-S and Candidate Elimination algorithms on the Enjoy Sports dataset and compare the hypotheses obtained from both approaches.

## Tools Used

- Python
- Jupyter Notebook / Google Colab
- Pandas
- NumPy

## Practical Work

- Loaded and inspected the Enjoy Sports dataset.
- Separated input attributes and target values.
- Implemented the Find-S algorithm.
- Generated the final hypothesis using positive examples.
- Implemented Candidate Elimination.
- Updated the specific and general boundaries.
- Compared the results produced by both algorithms.

## Conclusion

The practical demonstrates how concept-learning algorithms learn hypotheses from training examples. Find-S generates a single specific hypothesis, while Candidate Elimination maintains specific and general boundaries to represent the possible hypotheses.
